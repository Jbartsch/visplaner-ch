# Visplaner CH

Swiss fishing-waters **permit finder** prototype (inspired by [visplanner.nl](https://visplanner.nl/) — fishing map, not visas).

**Job:** What permit do I need for this water, and where do I buy it?

- Scope: **ZH + BE** (mock geometries & permit labels)
- Stack: Vite + React + TypeScript + MapLibre GL
- Disclaimer: informational only — **not** legal permission / digital patent
